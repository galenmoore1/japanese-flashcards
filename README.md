## Upload new vocab file (replacing old)

1. Open upload page
2. Click the Add file dropdown menu & select the Upload files option.
3. Match the filename. (Verify your new file matches the exact original name.)
4. Drag your new file into the browser window, or click the choose your files link.
5. Save the update:
   a. Enter a short commit message describing the change.
   b. Click the green Commit changes button.
